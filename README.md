# Comércio Fácil

Projeto Full Stack desenvolvido em equipe durante a formação da Recode Pro.

## Sobre o Projeto

O Comércio Fácil é uma aplicação web desenvolvida com foco em prática colaborativa de desenvolvimento Full Stack, utilizando tecnologias front-end e back-end para simular uma plataforma de comércio digital.

O projeto foi desenvolvido pela Squad25 durante a formação Recode Pro, proporcionando experiência prática com versionamento, trabalho em equipe e deploy em produção.

---

## Tecnologias Utilizadas

### Front-end
- HTML5
- CSS3
- Bootstrap
- JavaScript

### Back-end
- Java

### Ferramentas
- Git
- GitHub
- Render (Deploy)

---

## Funcionalidades

- Navegação entre páginas
- Interface responsiva
- Estrutura de comércio digital
- Integração entre front-end e back-end
- Deploy online da aplicação
