# 🛒 Comércio Fácil

Projeto Full Stack desenvolvido em equipe durante a formação Full Stack da Recode Pro.

O sistema foi criado com foco em simular uma plataforma de comércio digital, aplicando conceitos de desenvolvimento web, integração entre front-end e back-end, versionamento com Git/GitHub e deploy em ambiente cloud.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Java
- Bootstrap
- JavaScript
- Git
- GitHub
- Render (Deploy realizado durante o curso)

---

## 👨‍💻 Sobre o Projeto

O Comércio Fácil foi desenvolvido em grupo pela Squad25 como projeto final da formação Recode Pro.

Durante o desenvolvimento foram aplicados conceitos de:

- Estruturação de páginas web
- Responsividade
- Integração entre front-end e back-end
- Trabalho em equipe
- Versionamento de código
- Publicação da aplicação em produção

---

## 🎯 Funcionalidades

- Navegação entre páginas
- Interface responsiva
- Estrutura de comércio digital
- Organização de produtos e conteúdo
- Layout moderno utilizando Bootstrap

---

## ☁️ Deploy

Durante o período final do curso, o projeto foi publicado na plataforma Render como experiência prática de deploy e hospedagem de aplicações web.

Atualmente o deploy não se encontra mais online.
